# （核对过 21.2、23.0、24.2；25.1 起先试 UTF-8）按系统的本地编码读这个文件，Windows 上是 cp1252、
# GBK 这类，下面的中文注释会让 pip 直接报 UnicodeDecodeError、什么都不装。Python 3.10.11 建的
# .venv 里就是 23.0（PR #136 的 CI 上 Windows 那一格就是这样失败的）。
# 测试过的那一套依赖版本（专家审查 I4，用户决定 D8「按 Python 版本分开锁」）。
#
# 所有 pip install -r requirements.txt 都带着它：pip install -r requirements.txt -c constraints.txt。
# -c 只限定版本，不会因为写在这里就多装什么——没被 requirements.txt 拉进来的包，这里写了也不装。
# 以前 requirements.txt 只写下限，新装机拿到的是 PyPI 当天最新、从没一起跑过的组合，上游一出
# 大版本就可能起不来。
#
# 来源：2026-10-23 只读导出主人的 .venv（Apple 芯片 Mac、macOS 27、Python 3.13，直播一直在用的那套）
# 里实际装着的版本：requirements.txt 的依赖闭包，去掉下面「不锁的」。
#
# 每个包两行：
#   * 「锁死」（==，带环境标记）：只在 Python 3.11–3.14、而且是 x64 的 Windows（platform_machine 是
#     AMD64）或 Apple 芯片 Mac 的机器上。这些组合上，每一条锁死的版本 PyPI 上都有现成的安装包
#     （2026-10-23 逐个查过 PyPI 的文件列表；Windows 只查过 win_amd64）。ARM64 的 Windows 没查过，
#     不锁（ctranslate2 本来就没有 win_arm64 的安装包，原生 ARM64 的 Python 加锁前后都装不上）。
#     包自己要求更新的 Python 时（numpy、scipy 要 3.12 起），标记跟着它；在 Apple 芯片上只有 macOS 14
#     起才有安装包的（onnxruntime、torch、av、mlx、mlx-metal），再排除 macOS 11–13（Darwin 20–22）——
#     这里不能用 platform_release 比大小：Linux 的内核版本号（6.8.0-45-generic）不是合法版本号，
#     pip 求值时直接报错。
#   * 「上界」（<下一个大版本，不带标记）：所有机器都受它约束。锁死管不到的机器只受它约束：
#     Python 3.10、Intel Mac、macOS 13 及更早的 Apple 芯片 Mac、ARM64 的 Windows、Linux、Python 3.15
#     起。照 3.13 锁的版本在这些机器上没有现成的安装包（numpy 2.5.2 要 Python 3.12；onnxruntime 1.29.0、
#     torch 2.13.0 没有 Intel Mac 的安装包），带 -c 锁死会直接装不上。
#     日历版本号的包（packaging、flatbuffers、fsspec、regex）不设上界：它们的「大版本」只是年份。
#
# 不锁的（这里不写）：
#   * yt-dlp、curl_cffi：要追 TikTok 的变化。程序自己会在后台升级 yt-dlp（app/updater.py freshen_ytdlp）。
#   * TikTokLive：同一个道理。评论服务拒绝连接时程序会升级它（freshen_tiktoklive）；锁在这里的话，
#     下一次按清单补装会把它退回旧版本。
#   * 只经由上面这几个装进来的包，以及和它们共用的包（cffi、pycparser、certifi、httpx、protobuf、
#     pydantic……）：锁住它们，新版的 yt-dlp / TikTokLive 一要更新的依赖就装不上，pip 只能退回旧版本。
#
# 改了这个文件，.venv/.requirements.sha256 记的指纹就对不上（app/bootstrap.py 把 requirements.txt
# 和本文件一起算指纹）：已有的安装下次启动按新的版本补装一次，不重建 .venv。补装时整份带锁没装上、
# 回退去逐个装的某一步带锁也没装上（比如没联网、装着的版本又和这里的不一样），这一步不带锁再装一次，
# 和加锁以前一样，程序照常启动；24 小时后再按锁整份补装（app/bootstrap.install_requirements）。
# 升级某个组件（含安全更新）：改这里的版本号，看 CI 的 install-smoke 装不装得上。锁死的版本要在
# 上面说的每个组合上都有安装包。
