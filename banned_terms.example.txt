# 违禁词表 —— 一行一个词或短语，# 开头是注释，空行忽略
#
# 【怎么用】
# 程序首次启动会把本文件复制成同目录下的 banned_terms.txt，
# 请编辑那一份（banned_terms.txt），本文件保持原样即可。
# 分开两份是为了：你的词表不会被程序更新覆盖，也不会挡住「一键更新」。
# 改完保存后，点一次「停止」再「开始翻译」即可生效（不用重启程序）。
#
# 【匹配规则】写词的时候不用考虑这些，程序会自动处理：
#   * 大小写、重音符号都会被忽略（escándalo == escandalo == ESCANDALO）
#   * 单复数、阴阳性、指小词会自动匹配（producto → productos / producta / productito）
#   * ASR 听错一两个字母也能命中（5 个字母以上的词才启用模糊匹配）
#   * 多词短语即使被切在两段字幕之间也能命中（按最近 12 秒的文本匹配）
#
# 【写什么】建议直接写主播真实会说出口的说法，包括：
#   * 平台明令禁止的表述
#   * 夸大疗效 / 绝对化用语
#   * 主播为规避审查而使用的谐音、变体、黑话
#
# 【注意】词表越短越准。先放几十个真正会踩线的高频词，
# 跑一段时间看误报情况再慢慢加，比一次塞几百个泛词有效得多。
#
# 下面按类别给出格式示例（都被注释掉了，取消注释或替换成你们自己的词）：

# ---- 示例：绝对化 / 夸大疗效 ----
# cura el cáncer
# garantizado cien por ciento
# el mejor del mundo

# ---- 示例：医疗相关 ----
# medicamento sin receta

# ---- 示例：引流到站外 ----
# escríbeme a whatsapp
