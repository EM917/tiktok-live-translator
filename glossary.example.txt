# 【干什么用】这份表同时用在三个地方，一份数据三处生效：
#   1. 喂给语音识别做「热词」提示 —— 让 Whisper 别把 moringa 听成 morenga；
#   2. 拼进翻译提示词 —— 让商品名的译法固定下来；
#   3. 译文回来后做兜底替换 —— 模型没听话时用规则强制改正。
#
# 【怎么用】程序首次启动会把本文件复制成同目录下的 glossary.txt，
# 请编辑那一份（glossary.txt），本文件保持原样。改完点「停止」再「开始翻译」生效。
#
# 【重要】写**主播嘴里真会说的口语形式**，不是官网的书面商品名。
# 主播说的是 "las gotitas"、"el cafecito"、"el detox"，不会念完整产品名。
#
# 【变体】同一条可以用 | 分隔多个西语写法，它们都映射到同一个中文译法。
# 把 ASR 常听错的形式也写进去（西语口音把 skinny 念成 /esˈkini/，会被听成 esquini）。
#
# 【识别热词有上限】喂给 Whisper 的提示词约 244 token 上限，所以只有前
# 40 条会被用作识别热词（翻译和兜底替换不受此限）。**把最高频、最容易听错的
# 放在最前面**。换主播/换品类时应当换一份表。
