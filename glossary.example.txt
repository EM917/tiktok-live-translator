# ---- 以下来自 2026-08-24 一场实录的逐句复核（37 处确认错误）----

# 「做特价」。只收动词框架，不收裸的 en especial——后者在西语里同时保有
# 「尤其」的通用义（en especial las gotas de noche），裸词会误伤。
# 实录："Ahorita todos los tenemos en especial, chicos" 被译成「特别是对于年轻人」，
# 一句全场特价的价格承诺就此消失。
lo tenemos en especial | los tenemos en especial | está en especial | están en especial | en especialito => 在做特价

# 金额门槛，不是件数。实录："una orden de 30" 被译成「订购 30 瓶」——单品才 $21，
# 门槛被谎报了十几倍。
# 右侧写成「下单满（金额，美元）」是实测选出来的：写「订单满（美元）」模型照旧
# 输出「订购 30 支」，写「订单金额满」会掉成「30 元」。带上「金额」和「美元」
# 两个词才稳定把数字读成钱。变体必须带动词，裸的 orden de 命中率低且易误伤。
hacen una orden de | haces una orden de | hagan una orden de | con una orden de | es una orden de | por una orden de | en una orden de | una orden de => 下单满（金额，美元）

# 对观众的称呼，与年龄无关。实录里被译成「年轻人」，凭空捏造了一个人群定向。
chicos | chicas | muchachos | mi gente => 家人们

# 滴剂分日夜两版，是二选一的产品款式，不是服用时间。
# 实录："puedes elegir entre día o noche" 被译成「可以选择白天或晚上使用」。
entre día o noche | de día o de noche | versión de día | versión de noche => 日间版还是夜间版
las gotas de día | gotitas de día => 日间版滴剂
las gotas de noche | gotitas de noche => 夜间版滴剂

# 咖啡口味。horchata 是墨西哥米浆，不是杏仁奶；hongos 是三菌复配的蘑菇咖啡，
# 不能标成「灵芝」（上面第 44 行的灵芝是成分条目，不是商品名）；nuez 在这条
# 产品线里是碧根果。实录里 hongos 被吞掉、错成了「杏仁奶口味」。
la horchata | horchata | de horchata => 墨西哥米浆
el de hongos | de hongos | café de hongos | mushroom coffee => 蘑菇咖啡
el de nuez | de nuez | café de nuez => 碧根果

# 实录里 "café helado" 单独成段时被译成「冰激凌咖啡馆」——短句没有上下文，
# helado 的「冰淇淋」义会盖过「冰镇」义。
el café helado | café helado | iced coffee | el ice coffee => 冰咖啡

# ---- 高频口语。不是商品词，但错了整句意思就反了 ----
# 每一条都收窄到不会张冠李戴的写法——这些词的意思取决于后面跟什么，
# 语料实测同一个词在两种意思上都出现过（见下）。

# `un montón` 修饰**时长/程度**时是「很久、非常」。后面跟 `de + 名词` 时才是
# 「很多」，那种情况由下一条更长的写法接管（matching 长者优先）。
# 实录："estoy sentada un montón" 被译成「我坐了很多地方」——un montón 修饰的是
# 坐了多久，不是坐过几个地方；这一错把整段的前提（久坐所以要爬楼梯）毁了。
sentada un montón | sentado un montón | sentados un montón => 坐了很久
un montón de => 很多
trabajo un montón | estudio un montón | camino un montón => 很久

# 拉美西语里 `de vuelta` 是「再一次」，不是「返回」。
# 实录："Después lo hago de vuelta" 被译成「之后再反过来做」。
# 但 `de vuelta acá`（回到这里）确实是方位义，所以只收动词框架。
lo hago de vuelta | hacerlo de vuelta | lo hacemos de vuelta => 再做一遍

# 主播在对观众说话。拉美西语的第二人称复数是 ustedes，间接宾语正是 les，
# 所以 `les digo` 是「我跟你们说」。实录被译成「我会告诉他们」，
# 把观众变成了不在场的第三方，后面的演示也就没了对象。
les digo | les cuento | les voy a decir | déjenme les digo => 我跟你们说

# 直播/录影的工作场所，不是家里的书房（家里的会说单数带物主词 mi estudio）。
# 实录："yo acá estoy en los estudios" 被译成「我则在书房里」，
# 而下一句就是「我同事会看到我吗」——那是共用工作场所。
en los estudios | en el estudio => 在工作室

# puedas 是「做得到」，不是「想得到」。
de la forma que puedas | como puedas => 用你力所能及的方式

# ---- 对观众的称呼。只收**误译会让人搞错在跟谁说话**的那两个 ----
# 第二个主播（2026-08-25 实录）满口爱称，其中只有这两个是真的会误导：
#   mi niña  → 「我的女儿」  中控会以为主播在跟自己女儿说话
#   hermosa(s) → 「她们」/整个漏译  把在场的观众变成不在场的第三方
# 其余（amor / amorcito / reina / preciosa / mi vida）模型本来就译成
# 「亲爱的」，读得懂，不用管。
#
# 试过把它们全收进来映射成「亲」，实测更差：「亲」在句中插不进去，模型半用
# 不用，吐出 "paquetería amorcito → 爱邮递员"、"¡Vamos amorcitos! → 亲爱的人"、
# "listo amor → 爱了"。窄的那版把两条真错都修好了，且没有一处副作用。
# 又一次同样的规律：普通语言绑固定中文词，收得越宽伤得越多。
#
# **逐条查过语料才收**，这三个查完排除了：

#   mami    —— "Le ayuda mucho a mi mami"（对我妈妈很有帮助），真的是妈妈
#   linda   —— 单独出现的 "Linda" 是观众的名字
# 这里原来映射成「亲爱的」，现在改由 app/vocative.py 在翻译前直接摘掉。
