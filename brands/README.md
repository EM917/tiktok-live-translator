# 品牌词表

整场直播只卖一个牌子时，把这个牌子的商品词表放进这个文件夹，能提高商品名的
翻译正确率——道理和 `glossary.txt`、`profiles/*.txt` 一样：写死几十条商品名，
比指望通用模型自己听懂 "Quema Lonja" 这类自造词靠谱。这份说明不含任何真实
品牌内容，仓库里也不会带任何具体品牌的词表；下面举例用的 "acme" 是虚构品牌。

## 什么时候用

给**没有自己 `profiles/<主播>.txt`、但整场只卖同一个牌子**的直播间用。开始页
「本场品牌」下拉框选中它，这一场就会加载对应的商品词表；选「不限」（默认）
则完全不加载，行为和没有这个下拉框时一样。一场里混卖好几个牌子的货时不要选。

## 文件命名

`brands/<id>.txt`，`<id>` 只能是小写字母、数字和连字符（如 `acme`、
`acme-beauty`），不能有下划线、大写字母或空格。文件名决定下拉框里出现的
选项；程序不认识的文件名（大写、下划线、非 `.txt`，如这份 `README.md`）
会被忽略，不会出现在下拉框里。

下拉框的选项在打开这个文件夹、或点一下下拉框时会重新扫描，不用重启程序。

## 格式

和 `glossary.txt`、`profiles/*.txt` 完全相同：

```
写法1 | 写法2 => 中文译法   # 备注（可选，行内任意位置，# 后面都算注释）
```

一条可以用 `|` 分隔多个西语写法，都映射到同一个中文译法。可以在文件最前面
（或任意位置）单独写一行给这份词表起个显示名，不写就用文件名当显示名：

```
name: ACME 严选
```

示例（虚构品牌 acme，两个产品）：

```
name: ACME 严选

la crema acme | crema de acme => ACME 面霜
suero acme | el suero de acme => ACME 精华液
```

## 合并顺序

同一个西语写法在多层里都出现时，取最靠前的一层：**主播 profile > 本表 >
全局 glossary.txt**。全局表里的通用词条（成分、促销、物流、身材行话等）
照常生效——选了品牌词表只是不混进别的牌子的商品名，不是关掉通用词表。

## 何时生效

改完文件后，点一下「停止」再点「开始翻译」。正在直播中改文件不会立刻生效。

## 识别热词

本表最前面的几条，第一个写法会被喂给语音识别当「热词」提示（具体条数见
`app/glossary.py` 的 `BRAND_ASR_TERMS`）；提示词越长越容易被识别模型当成
上文续写进结果，所以只取最前几条，其余条目仍正常参与翻译提示和译文兜底。
**把最容易听错的专有名词放在最前面。**

## 写法注意事项

这几条都是实际用下来踩过的坑：

1. **匹配按子串、不看词边界**，不分大小写。写 `esquini` 这种常用词的前半截
   会连带命中 `esquinita`（角落）之类完全无关的词，字幕里凭空多出一句翻译。
2. 以 `el / la / los / las / un / una / unos / unas` 开头的写法，程序会自动
   也认 `tu / su / mi` 等物主词开头的说法。**两条译法不同的词条不能用「冠词 +
   同一个名词」开头**——`la crema` 和 `una crema` 都会自动变出 `tu crema`，
   两条译法会一起进提示词，互相打架。
3. **有歧义的词只收带冠词或修饰语的写法，不收单独一个词**：比如某个词单独出现
   时可能是普通词，只有前面带着某个特定修饰语才是商品名，就只写带修饰语的
   那个写法。
4. **译名只用品牌官方名称里已有的信息，不额外添加原名称里没有的功效描述**。
